# AWS Well-Architected Question Matrix

Scope: issue #17 planning for the bootstrap infrastructure repository. This matrix uses the current AWS Well-Architected Framework question set verified on 2026-04-26 and maps every question to current repository evidence, the gap to an evidence-backed 5/5, and the future evidence that must exist before any score increase is claimed.

The original planning package was planning-only. The rows below remain the
evidence contract for implementation PRs; adding implemented evidence here does
not raise a score unless the target evidence, owner, freshness, validation, and
fallback requirements are complete.

## Evidence Contract

Every target evidence item must record:

- Control owner: accountable human or team.
- Control location: repository file, workflow, AWS metadata source, dashboard, or external system of record.
- Evidence freshness: per PR, monthly, quarterly, or another explicit cadence.
- Review cadence: who reviews the evidence and how often.
- Fallback action: what happens if evidence is missing, stale, or contradictory.
- Secret-safety classification: public repo artifact, internal non-secret artifact, AWS metadata-only output, or secret-managed artifact that must not be printed.

## Claim Gate

A future implementation PR may raise a question score only when all of the following are true:

- The row for that question is updated with implemented evidence.
- Evidence is non-secret or documented as a secret-managed artifact that must not be printed.
- The relevant tests, policy checks, workflow checks, AWS metadata checks, or external-control attestations are linked.
- The owner and cadence are still valid.
- The implementation is compared with `main` so the review can identify whether the score improved, regressed, or stayed the same.
